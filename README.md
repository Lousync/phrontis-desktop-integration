# Phrontis 桌面集成包

> 这是一个**独立于 Phrontis 应用本体**的集成包 —— 定位就像你的 Neovim 配置：**应用提供接口，这里放「把它接进桌面」的那些东西**。
> 应用升级不会动到这里，这里改样式也不用碰应用。

## 为什么独立成包

应用内核里写死「顶栏长什么样」会带来两个问题：一是换个桌面环境就得改应用，二是每加一个落点（顶栏 / 系统菜单 / 托盘 / 命令行 / 日历）应用都要跟着发版。

所以这里只依赖**一个对外接口**，其余全是「消费者」，随时可以加、换、删：

| Neovim 里的东西 | 这里的对应物 |
|---|---|
| 内核 + 稳定 API | Phrontis 内核 + 对外接口（D-Bus，另附命令行镜像） |
| 插件（可独立仓库、任意语言） | `gnome-extension/`（GNOME 顶栏与系统菜单）、未来的 Waybar / rofi / KDE plasmoid |
| 你自己的配置仓库 | **本仓库** |
| API 向后兼容 | 接口带版本号，**只做加法** |

## 三层结构

```
Phrontis 内核（应用本体）
   └── 对外接口：D-Bus 服务 + 命令行镜像      ← 唯一契约，见 docs/interface.md
         ├── gnome-extension/                 ← 本仓库：GNOME 顶栏入口与弹出面板
         ├── 托盘图标菜单                      ← 应用自带（阶段 1 过渡 + 兜底）
         ├── 日历导出（.ics）                  ← 只读，接进系统日历
         └── 未来的其它落点                    ← Waybar / rofi / KDE …
```

## 目录

- `docs/interface.md` —— 对外接口规格（**v1 已实现**：Core1 核心通路）。**这是本仓库与应用之间唯一的契约。**
- `gnome-extension/` —— GNOME Shell 扩展（**骨架**；等 Core1 跑通后实现 A+B）。
- 原型（暂不入库）：`/home/lousync/Projects/Phrontis-linux/tmp/gnome-integration-proto/index.html`

## 三条硬原则

1. **插件不许直接碰数据文件。** 面板上勾一下，是「调接口」→ 应用走它自己的仓储层去写 → 广播刷新。数据只有一条写入通道（与应用内 AI 工具同一原则）。
2. **接口只覆盖「轻动作」**：看待办 / 勾待办 / 打卡 / 番茄钟 / 打开应用 / 搜索。**不含编辑笔记正文** —— 那是编辑器的事。
3. **未启动也能用**：接口支持 D-Bus 激活，点面板上的按钮会把应用自动拉起来。
