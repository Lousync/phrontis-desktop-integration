# 拍板记录（2026-10-19，原型 v1 体验后）

> 依据：可交互原型 `tmp/gnome-integration-proto/index.html`（应用仓库内，已 gitignore）体验后的选择。
> 本文件只记「已定」，未定的在 §3。

## 1. 形态

| 档 | 是什么 | 状态 |
|---|---|---|
| **A** | 顶栏常驻入口 + 弹出面板 | **采用** |
| **B** | 快速设置（Quick Settings）里的磁贴 | **采用** |
| **C** | 托盘图标 + 菜单（阶段 1 过渡 + 兜底） | **采用** |
| **D** | 嵌进日期时间下拉 | **不采用**（保留为实验位） |
| **E** | 做成 globalmenu 应用菜单里的一项「今日」 | **不采用**（2026-10-19 拍板；原型里保留作参考） |

## 2. 细节

| 项 | 决定 |
|---|---|
| A 的入口显示 | **图标 + 文字**「今日 N 项 · 打卡 M/K」 |
| 顶栏布局 | 时钟在**左上**（与 `just-perfection` 的实际配置一致）；Phrontis 入口**贴快速设置（右侧）** |
| 应用菜单（globalmenu 那一排） | **保留显示** |
| 打卡二次点击 | **取消打卡**（再点一下 = 撤销） |
| 番茄钟 | **完整功能**：开始 / 暂停 / 重置 + 倒计时显示 |
| 托盘图标 | **保留**，扩展装好后不自动隐藏 |
| Dock | 自动隐藏（沿用系统现状） |
| 深色样式 | 原型可切；正式按系统主题走（见下） |

## 3. 由拍板推出的阶段划分

- **阶段 1** = **C**（托盘菜单）+ 对外接口地基（D-Bus + CLI）。
  价值：立刻可用、验证数据通路、作为没有扩展时的兜底。
- **阶段 2** = **A + B**，在**同一个 GNOME 扩展**里实现两个落点（顶栏入口 + Quick Settings 磁贴）。
  比原计划省事：不用分两次做。
