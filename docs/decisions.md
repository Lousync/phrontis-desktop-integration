## 1. 形态

| 档 | 是什么 | 状态 |
|---|---|---|

## 2. 细节

| 项 | 决定 |
|---|---|
| A 的入口显示 | **图标 + 文字**「今日 N 项 · 打卡 M/K」 |
| 顶栏布局 | 时钟在**左上**（与 `just-perfection` 的实际配置一致）；Phrontis 入口**贴快速设置（右侧）** |
| 应用菜单（globalmenu 那一排） | **保留显示** |
| 打卡二次点击 | **取消打卡**（再点一下 = 撤销） |
| 番茄钟 | **完整功能**：开始 / 暂停 / 重置 + 倒计时显示 |
| 面板交互 | 勾选/打卡后**不关闭面板**；图标放大回弹；计数即时更新 |
| 面板待办范围 | **A：今天到期 + 逾期未完成**；不含待安排计划类 / 已完成 / 子任务（2026-10-20 拍板） |
| 托盘图标 | **保留**，扩展装好后不自动隐藏 |
| 托盘菜单内容 | **只放应用级动作**（显示 / 退出）；**不承载今日区**（2026-10-20 拍板，今日面板归扩展）；任务栏模式功能未完成，已移除 |
| Dock | 自动隐藏（沿用系统现状） |
| 深色样式 | 原型可切；正式按系统主题走（见下） |

## 3. 由拍板推出的阶段划分

- **阶段 1** = **C**（托盘菜单）+ 对外接口地基（D-Bus + CLI）。
  价值：立刻可用、验证数据通路、作为没有扩展时的兜底。
- **阶段 2** = **A + B**，在**同一个 GNOME 扩展**里实现两个落点（顶栏入口 + Quick Settings 磁贴）。
  比原计划省事：不用分两次做。

## 4. 未定

## 5. 实现状态（2026-10-20）

- **阶段 1 核心通路已落码**（应用侧）：D-Bus `Core1`（除 `PomodoroControl`）、托盘「今日」区、`phrontis-cli`、deb 注入。
- **阶段 2（A+B）扩展 v1 已落码**：顶栏「图标 + 今日 N 项 · 打卡 M/K」+ 弹出面板（勾待办 / 打卡 / 打开应用）、快速设置磁贴（同源读数）。
  - 只在 headless GNOME 50.1 里验证过 `enable()` 与面板/磁贴构造；**Wayland 实机需重新登录后看效果**。
  - 已发现并修掉一处 GNOME 50 API 变化：磁贴要挂到 `statusArea.quickSettings.menu`（`addExternalIndicator` 已移除）。
  - 番茄钟仍只显示状态，控制等 `PomodoroControl`。
  - **快捷键**：`Ctrl+Alt+S` 由扩展用 Mutter 原生 keybinding 注册（自带 GSettings schema），Wayland 下有效；
    Electron 的 X11 全局键只作扩展未启用时的兜底。应用托盘菜单另有「日程小窗」入口。
- 验收与契约：应用仓库 `docs/desktop-integration-plan.md` + `.AGENT/scripts/desktop-integration/verify-desktop-bridge.mjs`。
